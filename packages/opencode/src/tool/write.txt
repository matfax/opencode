Writes a file to the local filesystem.

Guidelines:
- This tool will overwrite the existing file if there is one at the provided path
- Only use it for trivial changes that depend on single-file contexts, such as documentation
- Prefer the edit and multi-edit tools for code changes
- If this targets an existing file, you MUST use the Read tool first to read the file's contents. This tool will fail if you did not read the file first
- ALWAYS prefer editing existing files in the codebase. NEVER write new files unless best practices or user instructions explicitly require it

Antipatterns to avoid:
- NEVER leave comment traces for removed code
- NEVER edit sections of code irrelevant to the instructions
- NEVER create duplicate code
- NEVER add emojis unless explicitly requested
- NEVER introduce any debugging statements unless explicitly requested
- NEVER proactively create documentation files (*.md) or README files unless explicitly requested
