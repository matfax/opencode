Facilitates modifications from natural language instructions to multiple related files using natural language instructions.

Usage:
- This autonomously handles file operations as instructed or necessary (create, delete, rename, move)
- Expects editing instructions in natural language describing what changes to make
- Accepts a list of existing and relevant files for context to understand how edits should integrate with the broader codebase
- Target folders, or non-existing files should be referenced in natural language in the instructions
- For simple changes, you can mention relevant integration references directly in the instructions to keep things concise
- For complex changes involving multiple files or intricate dependencies, provide the relevant file list for better context
- Unrelated aspects of the codebase should be invoked separately, not as part of the same edit request.
- Use this multi-edit tool for improved efficiency and context handling when multiple related files are involved.
- When using this tool, act in a mid-level planner role, like a senior developer, outlining crucial steps, requirements and references
