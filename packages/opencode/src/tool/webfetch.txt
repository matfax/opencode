Fetch the content of a web page and optionally format or summarize its content.

Features:
- Optionally converts the html to markdown for easier reading
- Can generate AI-powered summaries of web content
- Use this tool when you need to retrieve and analyze web content

Usage notes:
  - HTML format and auto-refresh should only be used for accessing the raw content for development purposes
  - For summary format, provide 1-2 sentences in the prompt describing what information you want to extract from the page

Use this tool when you need to retrieve and analyze web content and online documentation.
