Execute CLI commands with optional timeout. Supports direct command execution or agentic mode with tool-calling.

Usage:
- Provide `command` with `goal` (direct execution) or `goal` only (agentic mode with AI agent using tool-calling)
- For commands creating directories, use the List tool to verify parent directories first
- Always quote file paths with spaces (e.g., cd "path with spaces/file.txt")
- CLI output is truncated when exceeding the `limit` parameter (default 1,000 characters)
- In agentic mode, the agent returns its reasoning and summary (NOT truncated)
- Separate multiple commands with `;` or `&&` (not newlines)
- Avoid `cd` unless explicitly requested

Antipatterns to avoid:
- NEVER use this tool for reading or writing files. Use Read or Write tools instead
- NEVER use this tool for searching files. Use List, Glob, or Grep tools instead
